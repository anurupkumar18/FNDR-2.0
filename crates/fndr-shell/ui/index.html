    BEFORE CAPTURE

    You start capture deliberately.

    Opening FNDR does not request Screen Recording or collect context. Select Start capture only after you are ready for the macOS permission flow. This window receives generated lifecycle codes only—never screen pixels, OCR text, URLs, or model output.

    The menu-bar FNDR icon contains the explicit Quit FNDR control. It drains pending local writes before the host exits.
